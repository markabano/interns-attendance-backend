📌 Internship Attendance System — Backend

The Internship Attendance System is designed to solve the common problem interns face:
inaccurate computation and logging of working hours.

This backend provides a reliable, automated, and secure way to track attendance, store logs, and manage intern/admin access.

🚀 Features

🔐 Secure Authentication for interns and admins

🕒 Accurate Time Logging (clock in / clock out)

📅 Automatic Hour Computation

📊 Admin Dashboard API for monitoring intern activity

👤 Separate Intern & Admin Access Control

🗂️ MongoDB Database Integration

🧩 Modular and Scalable Node.js Backend

🌐 Ready for integration with any frontend or mobile app

⚙️ Tech Stack

Node.js

Express.js

MongoDB / Mongoose

JWT Authentication

🎯 Why I Built This

During my internship experience, I noticed inaccurate logging and computation of hours, which led to confusion and inconsistencies.
This system ensures fairness, accuracy, and transparency for both interns and administrators.
